# TypeScript Todo 

Detta är en enkel webbaserad to-do-applikation byggd i TypeScript. Syftet med projektet är att öva på TypeScript-syntax, förstå hur transpilering fungerar, samt använda localStorage och DOM-manipulation.

## Om uppgiften

Projektet är en del av kursmomentet för att lära sig TypeScript. Målet är att:
- Förstå vad TypeScript är och hur det skiljer sig från JavaScript.
- Använda interface, klasser och funktioner.
- Spara och hämta uppgifter från localStorage.

## Funktionalitet

- Lägg till nya uppgifter med prioritering
- Validering av input
- Spara uppgifter i localStorage 
- Radera uppgifter från listan

## Teknisk information

- Språk: TypeScript
- Verktyg: Vite 
- Publicering: Netlify
